# Структура репозитория

> Живой документ — обновляется по мере развития репозитория. Обновлено: **2026-07-31**.

Репозиторий **ПУБЛИЧНЫЙ**: <https://github.com/moykin/fluenta-wiki> → строго соблюдать [SECURITY.md](SECURITY.md).

Монорепо: приложение, бэкенд, маркетинг, дизайн и инфраструктура в одном месте — для соло-разработки это дешевле, чем синхронизировать несколько репозиториев.

## Дерево

```
fluenta.wiki/
├── app/          # Flutter — web, iOS, iPadOS, Android, macOS
├── backend/      # FastAPI — API, голосовой релей, разбор текста
├── marketing/    # лендинг, тарифы, SEO-куст — Jaspr (Dart)
├── design/       # дизайн-хэндофф
│   ├── README.md         # ГЛАВНОЕ: токены, экраны, состояния, правила
│   ├── *.dc.html         # 34 макета — держать ПЛОСКО, они ссылаются друг на друга
│   ├── support.js        # нужен рядом с макетами, иначе не откроются в браузере
│   ├── fluenta-*.js/css  # мобильный слой, произношение, word-art
│   ├── mascot/           # Люмен
│   ├── shots/            # скриншоты экранов
│   └── case-deck-plan.md # план портфолио-кейса
├── infra/        # docker-compose, Caddy, провижн сервера
│   └── .env.example      # плейсхолдеры; реальный .env — вне репо
├── docs/         # PROJECT, ARCHITECTURE, ROADMAP, REPO, SECURITY, POSITIONING
├── .github/workflows/    # CI
├── INFRA.local.md        # состояние сервера — GITIGNORED, вне публичного репо
└── .gitignore
```

## Что намеренно НЕ в репозитории

| Что | Почему |
|---|---|
| `Work under design*/` — zip-архивы дизайна | рабочие исходники, ~50 МБ; в репо лежит распакованная актуальная версия |
| `robot character*/` и `Gemini_Generated_Image_*.png` | ~25 МБ исходников маскота; в репо только готовые позы в `design/mascot/` |
| `design/uploads/` из архива | рабочие скриншоты, включая личные аккаунты |
| `design/shots/deck/` | 14 МБ картинок для презентации |
| `INFRA.local.md`, любые `*.local.md` | операционные детали инфраструктуры |

Порог простой: репозиторий держим лёгким (~7 МБ) и без Git LFS. Всё, что тяжелее и не нужно для сборки, остаётся локально.

## Правила

- Макеты `*.dc.html` — **референсы, не продакшен-код**. Их воссоздают во Flutter, а не подключают.
- Файлы макетов **не раскладывать по подпапкам** — сломаются взаимные ссылки и `support.js`.
- Секреты — только через `.env` вне репо (см. [SECURITY.md](SECURITY.md)).
- Папки `Work under design ` и `robot character ` на диске имеют **хвостовой пробел** в имени — учитывать в скриптах.
