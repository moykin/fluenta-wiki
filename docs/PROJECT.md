# Fluenta — обзор проекта

> Домен `fluenta.wiki`. Живой документ, обновлено: **2026-07-31**.

**Fluenta превращает то, что вы читаете, в то, что вы можете сказать.**

Кроссплатформенное приложение (веб для телефона/планшета/ПК + приложения для iOS, iPadOS, Android, macOS) для обучения иностранному языку вокруг одного цикла: **читать → понять «почему» → пересказать вслух → получить одну правку → повторить, когда начинаешь забывать**.

> **Мультиязычность:** не только английский→русский — много языковых пар (язык изучения для чтения + родной язык для перевода и объяснений).

## Два ядра продукта

1. **Чтение с разбором.** Пользователь читает текст на изучаемом языке; тап по слову — мгновенный перевод, выделение фрагмента — объяснение ПОЧЕМУ перевод такой: грамматика, изменения форм слов (base form → used form + причина), идиомы, порядок слов.
2. **Голосовой AI-тьютор.** Пользователь пересказывает прочитанное вслух, ИИ проверяет запоминание и язык, даёт **одну** правку. Цель — закрыть «output gap» (читаю, но не говорю).

## Аудитория и позиционирование

Продвинутые ученики **B1–C2**, премиум-продукт. Ниша между читалками (нет устной практики) и голосовыми тьюторами (нет глубокой работы с текстами). Подробнее о посыле и тоне — [POSITIONING.md](POSITIONING.md).

## Ключевые продуктовые решения

- **Двухуровневый перевод:** тап — мгновенный локальный перевод без лоадера; выделение фрагмента — глубокий LLM-разбор в панели/bottom sheet.
- **Правило одной правки:** тьютор всегда даёт ровно одну коррекцию; ошибки автоматически становятся карточками на завтра 09:00.
- **FSRS по ПРЕДЛОЖЕНИЯМ, не по словам.** Again/Hard/Good/Easy.
- **Голос:** real-time, низкая задержка, barge-in. Микрофон запрашивается только в момент пересказа, есть текстовый fallback. Запись по умолчанию НЕ хранится — остаются только ошибки; хранение включается тумблером (Pro; Free — 1 раз в месяц).
- **Прогресс:** heatmap вместо streak, «минут речи», уровень + «B2 ≈ IELTS 5.5–6.5 · TOEFL 72–94».
- **Карьера:** 10 профессиональных треков (IT, дизайн, продажи, финансы, наука, медицина, сварка, монтаж, электрика, сантехника): самопрезентация 30с/90с, термины с IPA, mock interview с таймером и S-T-A-R, разбор вакансии, «Спринт к собеседованию» на 6 шагов.
- **Импорт своих текстов** (PDF/EPUB/URL), «% знакомых слов», офлайн-first + синхронизация.
- **Инклюзивность:** dyslexia-friendly режим, TTS.

## Монетизация (без dark patterns)

Считаются **только голосовые минуты** — пересказ, тьютор, mock interview. Чтение и повторения не имеют счётчика. Слово «безлимит» не используется.

| Тариф | Что даёт |
|---|---|
| **Free** | ≈15 голосовых минут в месяц (примерно 1 пересказ в неделю); 1 трек «Карьеры» со сменой раз в месяц |
| **Pro** | 150 голосовых минут в месяц ≈ 25 пересказов; все треки |
| **Пакеты минут** | +60 мин за $6, +180 мин за $15 |

Перед сессией — честное предупреждение («займёт ~12 мин из 128, останется 116»). При нуле минут сначала предлагаются пакеты, потом подписка. Учёт минут и гейтинг — **на сервере**.

## Технологический стек

Кратко: **Flutter** (web, iOS, iPadOS, Android, macOS) + **Python/FastAPI** + **PostgreSQL с pgvector**; голос — **Gemini Flash Live** через серверный релей; разбор — **spaCy + spacy-llm**; повторения — **FSRS**. Обоснование выбора и открытые вопросы — [ARCHITECTURE.md](ARCHITECTURE.md).

## Дизайн

Дизайн-система утверждена, экраны отрисованы в high-fidelity: светлый минимализм, typography-first. Фон `#FAFAF8`, текст `#1A1A1A`, вторичный `#6B7280`, акцент индиго `#4F46E5`, янтарный `#FBBF24` (сохранённые слова), success `#10B981`, бордеры `#E5E7EB`. Текст для чтения — Source Serif 4, UI — Inter. Радиусы 9–18px, тач-цели ≥44px. Маскот — **Люмен**.

Полный хэндофф с токенами, экранами и состояниями — `design/README.md`.

## Статус

- Дизайн: **готов** (34 экрана + карты состояний).
- Код: **этап Э0→Э1** — см. [ROADMAP.md](ROADMAP.md).
- Инфраструктура: сервер куплен, провижн не сделан.
