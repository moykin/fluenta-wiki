# Handoff: Fluenta.wiki — веб-версия и приложение

## Обзор
Fluenta — тренажёр языка вокруг одного цикла: **читать → понять «почему» → пересказать вслух → получить одну правку → повторить, когда начинаешь забывать**.

**Ключевое позиционирование (обязательно на всех поверхностях, формулировку не менять):**
- RU: «Fluenta превращает то, что вы читаете, в то, что вы можете сказать.»
- EN: "Fluenta turns what you read into what you can say."
- Маркетинг: крупное утверждение или индиго-пилюля (#EEF2FF фон, #E0E7FF бордер, #4338CA текст, radius 9–10px, 12–12.5px, line-height 1.45, text-wrap: pretty).
- В приложении: тихая строка «Цель — превратить то, что вы читаете, в то, что вы можете сказать» (12.5px, #9CA3AF).
- «Читать → пересказывать → повторять» — механика, идёт ПОСЛЕ посыла, не вместо.

## О файлах
Все `*.dc.html` в корне проекта — **дизайн-референсы в HTML** (прототипы вида и поведения), не продакшен-код. Задача разработчика — воссоздать их в целевом стеке (React/Vue/SwiftUI/Kotlin и т.п.) по паттернам своей кодбазы; если кодбазы нет — выбрать фреймворк и реализовать по этим макетам. Файлы открываются в браузере напрямую (нужен `support.js` рядом — он в архиве).

## Fidelity
**High-fidelity.** Цвета, типографика, отступы, тексты и состояния — финальные; воспроизводить точно. Исключение: карты (`Screen Map`, `Flow Map`, `Visual Map`) и `Responsive QA` — служебные артефакты для ревью, их реализовывать не нужно.

## Адаптив (телефон / планшет / ПК)
Стратегия — fluid-вёрстка, почти без брейкпоинтов:
- Размеры через `clamp()` (заголовки, паддинги), сетки `repeat(auto-fit|auto-fill, minmax(...))`, ряды `flex-wrap:wrap` — страницы корректны от ~360px до 1440px+.
- `fluenta-mobile.css` — общий мобильный слой приложения: сжатие шапки, нижние табы `.fl-tab`, класс `.fl-page`, тач-цели ≥44px. `fluenta-mobile.js` — bottom-sheet и long-press.
- Онбординг: `Fluenta Onboarding.dc.html` = телефон (рамка 390×844) и планшет (834×1112, контент в колонке 560px) — переключатель под рамкой; `Fluenta Onboarding Desktop.dc.html` = ПК (двухколоночный: текст слева, шаги справа). В реальном приложении это один экранный поток с тремя лэйаутами.
- Проверочная страница: `Fluenta Responsive QA.dc.html` — все экраны в трёх вьюпортах (390 / 834 / 1280).

## Экраны (файл → назначение)
**Маркетинг**
- `Fluenta Landing.dc.html` — лендинг: hero с посылом и выбором пары языков, живое демо читалки, механика, свои тексты, сообщество, сравнение с репетитором, FAQ, футер.
- `Fluenta Pricing.dc.html` — тарифы: Free ≈15 голосовых мин/мес (1 пересказ в неделю), Pro 150 мин/мес ≈ 25 пересказов, пакеты +60 ($6) и +180 ($15); чтение/повторения без счётчика; слово «безлимит» не используется.
- `Fluenta About.dc.html` — история, «Одна цель» (посыл), блок «0 инвесторов · 1 человек».
- `Fluenta SEO Pillar / Texts / Texts B1 / Grammar / Video / Career .dc.html` — SEO-куст; Career = воронка «английский для собеседования»: output gap, 10 профессий, план на 14 дней (бюджет минут), ответ до/после, FAQ.

**Онбординг (3 минуты, ценность до регистрации)**
Экраны: 1 вопрос о языке → текст 160 слов → тап по фразе = попап-каскад (перевод → «почему» → «нельзя просто talked») → пересказ 30 сек (тумблер «Сохранить эту запись»: Pro, Free 1/мес) → одна правка «Почти идеально» (go→went) → aha-экран «Эта ошибка вернётся завтра» (кривая забывания, точка «завтра 09:00») → мягкая стена «Сохранить прогресс?» + чипы «Зачем вам язык?» (работа/путешествия/переезд/семья/учёба; работа включает карьерный трек). Регистрация только в конце; «Пока без аккаунта» — прогресс локально.

**Приложение**
- `FluentaShell.dc.html` / `FluentaShell2.dc.html` — навигация (Библиотека · Читалка · Тьютор · Повторение · Карьера · Прогресс · Профиль), мобильные табы.
- `Fluenta Library v2.dc.html` — библиотека (v1 удалена). `Fluenta Reader.dc.html` — читалка с разбором «почему так». `Fluenta Tutor.dc.html` — голосовой тьютор; в шапке чип остатка минут «128 / 150 мин». `Fluenta Review.dc.html` — FSRS-повторения. `Fluenta Video.dc.html` — видео (не развивать до релиза).
- `Fluenta Career.dc.html` — Карьера: 10 треков (IT, дизайн, продажи, финансы, наука, медицина, сварка, монтаж, электрика, сантехника). Модули: самопрезентация (30с/90с/«почему вы»), термины с IPA и произношением (`fluenta-speak.js`), mock interview (таймер, минуты, S-T-A-R полосы), STAR-шаблоны, разбор вакансии, тексты профессии. Вид «Спринт к собеседованию» (6 шагов, ±дни). Гейтинг: Free — 1 трек (смена раз в месяц), остальные Pro.
- `Fluenta Progress.dc.html` — прогресс: слова, сессии, «минут речи», уровень + «B2 ≈ IELTS 5.5–6.5 · TOEFL 72–94».
- `Fluenta Profile.dc.html` — профиль: счётчик 74/150 мин, журнал расхода, пакеты, тариф.
- `Fluenta Admin.dc.html`, `Fluenta Admin Add Text.dc.html` — админка.

**Бренд/кейс:** `Fluenta Mascot Kit` (Люмен, `mascot/`), `Fluenta Store Screenshots`, `Fluenta Case Deck (EN)` — деки через `deck-stage.js`.

## Взаимодействия и состояния
- Правило одной правки: тьютор всегда даёт ОДНУ коррекцию, ошибки → карточки на завтра 09:00.
- Голосовые минуты: расходуют только пересказ/тьютор/mock; предупреждение перед сессией («займёт ~12 мин из 128, останется 116»); при 0 — сначала пакеты, потом подписка. Порог окраски остатка: >30% индиго #4F46E5, ниже — янтарный #F59E0B.
- Запись пересказа: по умолчанию НЕ хранится (остаются только ошибки); тумблер включает хранение (Pro / Free 1 в месяц) и добавляет мотиватор на экране регистрации.
- Микрофон запрашивается только в момент пересказа; нужен текстовый fallback (в макетах помечено как улучшение).
- Hover: кнопки #4F46E5→#4338CA; карточки border→#C7D2FE; появление блоков — fade+6px 0.2–0.24s ease-out.
- Пустые/ошибочные состояния см. `Fluenta Screen Map.dc.html` (44+ состояний, красные метки = точки потерь: запрос микрофона, отклонённая карта).

- Шрифты: заголовки и «язык» — 'Source Serif 4' (serif); UI — 'Inter' (Google Fonts). Кегли UI 11–15px, читалка 17.5–18.5px/1.72–1.75, H1 clamp(26–52px).
- Радиусы: кнопки/поля 9–12px, карточки 14–18px, пилюли 999px. Тени: карточка 0 1px 2px rgba(26,26,26,.04); поднятая 0 10px 28px rgba(79,70,229,.10).
- Тач-цели ≥44px на мобильных.
